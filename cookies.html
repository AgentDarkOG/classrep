Cookies and tracking

Last updated: 30 September 2026

The current preview code does not set cookies, save site state in browser storage, run analytics, or load advertising trackers. The homepage clears old demo cart and order entries when browser storage is available. Owner listing drafts stay in page memory until downloaded. Owner sign-in uses the browser's HTTP Basic Authentication prompt, not an app-set cookie; the browser may remember the sign-in according to its own settings.

Site resources

The page loads its background video files from the same site. It does not embed third-party media or request fonts from an external provider. The hosting provider may process technical connection data when delivering the page, according to its own configuration and terms.

The host may also apply technical or security cookies independently of this page. Its behavior depends on the hosting provider and configuration, which must be checked before publication.

Consent

There are no optional cookie or analytics controls in this preview because those features are not enabled. If cookies or other tracking are introduced, explain their purposes and providers and add appropriate user controls before enabling them.
